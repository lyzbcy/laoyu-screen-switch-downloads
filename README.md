捞鱼屏幕开关 1.0.0：解压即用，默认 Alt+1 关屏、Alt+2 亮屏，可自定义。

提供系统显示器待机、黑屏遮罩两种模式，托盘操作、独立 BAT、单实例接续与紧急恢复。BAT 使用纯英文 ASCII，实测中文、空格和 & 路径。配置与日志只保存在本机；无需管理员权限，不联网。

Windows 10 64 位已实际验证快捷键、像素黑屏、系统显示状态灭/亮、自定义与冲突回退、BAT 入口、重复启动、退出恢复。Windows 11、Windows 7 SP1/8.1 属兼容设计，尚未实机验收。独占全屏游戏和酒店管理策略可能影响快捷键或遮罩。

下载 LaoyuScreenSwitch-Windows.zip，解压整个文件夹；双击 LaoyuScreenSwitch.exe 设置，或双击 screen-off.bat 直接关屏。screen-on.bat 亮屏，screen-exit.bat 退出。

黑屏遮罩只遮画面，背光仍亮。系统待机能否关闭背光取决于显示器/驱动，输入可能唤醒。紧急亮屏：Ctrl+Alt+Shift+F12。
