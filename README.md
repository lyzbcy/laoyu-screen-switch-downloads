捞鱼屏幕开关 1.1.0

Windows 正式版 + Mac 通用回归版，统一捞鱼小鱼标志，奶油白和森林绿界面。Windows 默认 Alt+1 / Alt+2；Mac 默认 Option+1 / Option+2，支持自定义快捷键、系统待机与黑屏遮罩，关闭窗口后在托盘 / 菜单栏继续运行。双击 BAT / command 可以直接关屏。

新增每天北京时间首次检查正式新版、手动重试、校验下载与更新重启、明显的“遇到问题反馈”和离线作者页。反馈由用户主动发送，可选分类、备注、诊断预览与附件取消；企业微信接收地址只存本机，不预置私人 webhook。软件没有遥测。1.0.0 用户首次需要手动解压新版。

Windows 已实际验收开关屏、快捷键与占用回退、真实黑屏像素、电源状态恢复、BAT 中文/空格/&路径。Mac 已在 macOS 15.7.9 构建机编译为 Intel / Apple Silicon 通用应用，实际验收热键注册、黑屏像素、窗口恢复、睡眠/唤醒通知及配置保存。用户 Mac 的实际按键、显示器和日常场景回归由用户自行完成。

下载方式：
- Windows：LaoyuScreenSwitch-Windows.zip，解压后运行 LaoyuScreenSwitch.exe；screen-off.bat 关屏、screen-on.bat 亮屏。
- Mac：LaoyuScreenSwitch-macOS-universal.zip，解压后打开“捞鱼屏幕开关.app”；screen-off.command / screen-on.command 提供双击入口。

Mac 应用已 ad-hoc 签名但尚未 Apple 公证，首次若被阻止，在系统设置 → 隐私与安全性选择仍要打开。正常功能无需辅助功能或录屏权限。

Windows 软件中心 0.8.1 已登记此软件的下载、校验、解压准备和打开；0.8.0 及更早客户端请先更新。网页版分平台提供 Windows 和 Mac 文件。

黑屏遮罩仅遮画面，背光仍亮。系统关屏的真实待机取决于驱动/硬件，普通输入可能唤醒。退出会亮屏；紧急恢复 Windows 为 Ctrl+Alt+Shift+F12，Mac 为 Control+Option+Shift+F12（媒体功能键机型可能还需 Fn）。
